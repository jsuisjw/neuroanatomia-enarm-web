# neuroanatomia-enarm-web

Página web interactiva sobre bases neuroanatómicas y neurofisiológicas del sistema nervioso, enfocada en localización neurológica y preguntas ENARM.

## Cómo ver la página

1. Abre el archivo `index.html` directamente en tu navegador, o
2. En la terminal del proyecto ejecuta:

```bash
python -m http.server 8000
```

Luego entra a:

```text
http://localhost:8000
```

## Contenido

- Introducción a neuroanatomía y neurofisiología
- Secciones de localización clínica
- Banco de preguntas interactivas para repaso ENARM
- Diseño responsivo para desktop y móvil

## Archivos principales

- `index.html` — estructura de la página
- `styles.css` — estilos visuales
- `script.js` — preguntas interactivas y lógica del quiz
