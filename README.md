# neuroanatomia-enarm-web

Aplicación web interactiva (React + TypeScript + Vite) para el **Tema 1: Bases neuroanatómicas y neurofisiológicas** con foco en localización neurológica.

## Incluye

- Menú jerárquico con **1.1 Hemisferios cerebrales** como contenedor de:
  - 1.1.2 Lóbulo frontal
  - 1.1.3 Lóbulo parietal
  - 1.1.4 Lóbulo temporal
  - 1.1.5 Lóbulo occipital
  - 1.1.6 Ínsula
- Capítulos principales 1.2–1.10 con esquema obligatorio de localización.
- Sección **ENARM Neuroanatomía y Semiología: preguntas de localización** con 50 preguntas de opción múltiple, retroalimentación inmediata, explicación de distractores, perla ENARM y referencia editable.
- Filtros por categorías oficiales y filtros específicos para subtemas de hemisferios.

## Scripts

npm install
npm run dev
